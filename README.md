# POKEDEX // Secret Link

Это автономный PWA-квест: телефон выглядит как настоящий электронный Покедекс, получает сообщение профессора, показывает миссии, проверяет секретные коды и запускает финальное поздравление.

Проект сделан как статическое приложение: HTML, CSS, JavaScript, JSON, изображения и аудио. Сервер и база данных не нужны.

## Структура проекта

- `index.html` - экран Покедекса для ребёнка.
- `admin.html` - родительская панель настройки.
- `style.css` - внешний вид Покедекса.
- `script.js` - логика приложения, её обычно не нужно менять.
- `admin.css` - внешний вид панели настройки.
- `admin.js` - логика панели настройки.
- `config.json` - название устройства, состав команды, тексты интерфейса, громкость, вибрация, финал.
- `missions.json` - список миссий, коды, тексты, картинки и аудио миссий.
- `flow.json` - порядок экранов и сценарий прохождения.
- `achievements.json` - достижения команды.
- `content/project.json` - главный индекс контентного проекта: какие JSON-файлы использовать.
- `content/screens.json` - библиотека экранов и универсальных компонентов.
- `content/texts.json` - словарь повторяющихся текстов и подписей.
- `content/images.json` - библиотека изображений, сцен и декоративных ресурсов.
- `content/audio.json` - библиотека музыки, голосов и эффектов.
- `content/effects.json` - настройки анимаций, задержек и визуальных реакций.
- `content/codes.json` - структура главного шифра и кодовых фрагментов.
- `timelines/` - таймлайны для точной смены медиа во время аудио.
- `manifest.json` - настройки PWA для установки на главный экран.
- `service-worker.js` - офлайн-кэш PWA.
- `images/` - все изображения.
- `audio/` - все аудиофайлы.
- `fonts/` - папка для локальных шрифтов, если они понадобятся.

## Командный режим

При первом запуске после boot-экрана Покедекс открывает регистрацию команды:

1. Дети вводят название команды.
2. Покедекс проверяет название: от 3 до 30 символов, без опасных спецсимволов.
3. Покедекс автоматически выдаёт номер отряда.
4. Покедекс сканирует участников из заранее подготовленного списка.
5. Покедекс автоматически подтверждает найденный состав.
6. Покедекс сам устанавливает защищённое соединение и запускает сообщение профессора Оука.

Данные команды сохраняются в прогрессе:

- название команды;
- номер отряда;
- участники;
- статус;
- достижения.

Командный прогресс отображается в HUD:

```text
ОТРЯД №---
СПАСЕНО ПОКЕМОНОВ
0 / 8
```

## Как изменить правила команды

Откройте `config.json`, раздел `team`.

Там можно изменить:

- `minNameLength` - минимальная длина названия команды;
- `maxNameLength` - максимальная длина названия команды;
- `minMembers` - минимальное количество участников;
- `maxMembers` - максимальное количество участников;
- `defaultStatus` - начальный статус;
- `finalStatus` - финальный статус;
- диапазон номеров отряда.

Список участников находится в `defaultTeam`. У каждого участника есть имя и флаг `active`.

```json
{
  "name": "Матвей",
  "active": false
}
```

Если `active` равно `false`, Покедекс не покажет этого участника во время сканирования.

Тексты сцен регистрации, сканирования и соединения находятся в `teamScreens`.

Способ через панель:

1. Откройте `admin.html` через опубликованную HTTPS-ссылку или `localhost`.
2. В блоке `Состав команды` отметьте детей, которые участвуют в празднике.
3. При необходимости измените имена или добавьте нового участника.
4. Нажмите `Сохранить для этого устройства`.
5. Откройте `index.html` на этом же устройстве.

## Как заменить логотип

1. Подготовьте файл логотипа.
2. Положите его в папку `images/`.
3. Если имя файла такое же, как в `config.json`, например `logo.svg`, больше ничего делать не нужно.
4. Если имя другое, откройте `config.json` и поменяйте поле `app.logo`.

## Как заменить картинки

Самый простой способ:

1. Откройте папку `images/`.
2. Замените нужный файл новым файлом с тем же именем.
3. Например, замените `mission01.svg` на свою картинку с тем же именем.
4. Приложение автоматически использует новый файл.

Если имя файла меняется:

1. Откройте `missions.json`.
2. Найдите нужную миссию.
3. Измените поле `image`, например на `images/my-mission.png`.

## Как заменить озвучку

1. Откройте папку `audio/`.
2. Положите новый файл с тем же именем.
3. Например, замените `oak_message.wav`.
4. Приложение автоматически использует новую запись.

Если у миссии своё аудио, укажите его в `missions.json`:

```json
"audio": "audio/mission01.wav"
```

## Как добавить новую миссию

1. Откройте `missions.json`.
2. Скопируйте последний объект миссии.
3. Вставьте его ниже через запятую.
4. Измените `id`, `title`, `description`, `image`, `audio`, `code`, `successText`.
5. Сохраните файл.

Пример миссии:

```json
{
  "id": 9,
  "title": "Новая миссия",
  "description": "Найдите подсказку и введите код.",
  "image": "images/mission09.png",
  "audio": "audio/mission09.wav",
  "slides": [],
  "code": "CODE",
  "successText": "Миссия выполнена.",
  "successAudio": "audio/mission_success.wav",
  "backgroundMusic": "",
  "enabled": true
}
```

Количество миссий может быть любым.

## Как изменить сценарий прохождения

Порядок экранов задаётся в `flow.json`. Самый простой способ изменить его без программирования - открыть `admin.html` и использовать блок `Редактор сценария`.

В редакторе можно:

- менять порядок этапов кнопками `Выше` и `Ниже`;
- перетаскивать этапы мышью;
- отключать отдельные этапы;
- добавлять новый этап;
- указать миссию, аудио и таймлайн для этапа.

После сохранения Покедекс использует новый порядок на этом устройстве сразу.

Пример шага:

```json
{
  "id": "mission_1",
  "type": "mission",
  "missionId": 1,
  "next": "mission_2"
}
```

Типы шагов:

- `boot` - запуск устройства.
- `incoming` - входящее сообщение.
- `audio` - воспроизведение аудио с таймлайном.
- `mission` - миссия из `missions.json`.
- `victory` - финальный экран.

Чтобы добавить аудио-сообщение между миссиями:

1. Добавьте mp3 в `audio/`.
2. При необходимости создайте JSON в `timelines/`.
3. Добавьте шаг в `flow.json`.
4. Поменяйте `next` у предыдущего шага.

## Таймлайны аудио

Таймлайн позволяет менять изображение строго в заданный момент аудио.

Пример файла из папки `timelines/`:

```json
{
  "audio": "audio/oak_message.wav",
  "events": [
    {
      "time": 0,
      "type": "media",
      "target": "message",
      "media": {
        "type": "image",
        "src": "images/message01.svg",
        "alt": "Первый кадр"
      }
    }
  ]
}
```

`time` указывается в миллисекундах.

## Как изменить секретный код

1. Откройте `missions.json`.
2. Найдите нужную миссию.
3. Измените поле `code`.
4. Сохраните файл.

Регистр букв не важен: `pika`, `PIKA` и `PiKa` будут приняты одинаково.

В текущей версии сценарий заблокирован под `Книгу ведущего версия 2.docx`: коды миссий зафиксированы в `content/codes.json`, поле `mainCipher.locked: true`. Это защищает квест от старых локальных настроек браузера.

Финальный код лаборатории: `975384`. Он собирается из первых цифр кодов спасённых покемонов в обратном порядке.

## Как отключить миссию

В `missions.json` поменяйте:

```json
"enabled": false
```

Миссия останется в файле, но Покедекс пропустит её.

## Типы командных миссий

В `missions.json` у каждой миссии есть поле `type`.

Поддерживаемые значения:

- `team` - командная миссия;
- `search` - поисковая миссия;
- `logic` - логическая миссия;
- `creative` - творческая миссия;
- `physical` - физическая миссия.

Это поле нужно для структуры сценария и будущей настройки отображения. Логика движка не зависит от конкретной тематики.

## Достижения команды

Достижения лежат в `achievements.json`.

Пример:

```json
{
  "id": "first_badge",
  "title": "Первый значок получен",
  "description": "Отряд успешно прошёл первое испытание",
  "icon": "images/badge01.svg",
  "missionId": 1
}
```

Когда команда выполняет миссию с указанным `missionId`, достижение сохраняется в данных команды.

## Слайды во время аудио

У сообщения профессора слайды задаются в `config.json`:

```json
"slides": [
  "images/message01.svg",
  "images/message02.svg"
]
```

У каждой миссии слайды задаются в `missions.json`:

```json
"slides": [
  "images/mission01-a.png",
  "images/mission01-b.png"
]
```

Скорость смены слайдов меняется в `config.json`:

```json
"slideIntervalMs": 2400
```

## Панель администратора

`admin.html` нужна только родителям.

Она позволяет:

- изменить название устройства;
- изменить имя профессора;
- изменить состав команды и временно отключить отсутствующих участников;
- изменить тексты миссий;
- изменить секретные коды;
- включить или отключить миссии;
- изменить порядок миссий;
- изменить порядок экранов в сценарии;
- загрузить изображение или аудио;
- изменить финальное поздравление;
- включить или выключить Party Mode и Debug;
- импортировать или экспортировать весь проект одним JSON-файлом;
- скачать обновлённые `config.json` и `missions.json`.

Кнопка `Сохранить для этого устройства` сохраняет изменения в браузере на текущем телефоне или компьютере. `index.html` сразу использует эти данные на этом же устройстве.

Для быстрой резервной копии нажмите `Экспорт проекта`. Скачается один файл `pokedex-project.json`, в котором находятся настройки, миссии, сценарий и достижения.

Для постоянной публикации отдельных файлов нажмите:

1. `Скачать config.json`.
2. `Скачать missions.json`.
3. Замените этими файлами файлы проекта.
4. Опубликуйте проект заново.

Если вы переносите настройки на другой телефон:

1. На первом устройстве откройте `admin.html`.
2. Нажмите `Экспорт проекта`.
3. На втором устройстве откройте `admin.html`.
4. В блоке `Импорт / экспорт проекта` выберите скачанный файл.
5. Нажмите `Сохранить для этого устройства`, если хотите закрепить импортированные данные.

## Тестовый режим

Тестовый режим нужен родителям.

Открыть его можно двумя способами:

1. Долго удерживать надпись `POKÉDEX` в верхней части устройства.
2. Ввести секретный код из `config.json`, поле `testModeCode`. По умолчанию это `ADMIN`.

В тестовом режиме можно:

- перейти к любому экрану из `flow.json`;
- открыть любую миссию;
- проиграть любой загруженный аудиофайл;
- запустить тестовую вспышку;
- сбросить прогресс;
- очистить `LocalStorage`;
- посмотреть текущее состояние приложения.

В Party Mode debug скрыт, но тестовый режим всё ещё доступен родителям через долгий тап или код `ADMIN`.

## Продолжение прохождения

Приложение сохраняет прогресс в `LocalStorage`:

- текущий шаг сценария;
- текущую миссию;
- название команды и номер отряда;
- участников команды;
- достижения команды;
- выполненные миссии;
- введённые коды.

Если закрыть приложение во время квеста, при следующем запуске появится окно:

```text
ОБНАРУЖЕНО НЕЗАВЕРШЁННОЕ ПРОХОЖДЕНИЕ
```

Можно продолжить или начать заново.

## Debug-панель

Debug-панель включается так:

```text
index.html?debug=1
```

Быстрый Debug Overlay можно включить и выключить клавишей `F2`. Он показывает реальные данные текущей миссии:

- Mission ID;
- Source;
- Pokemon;
- Card code;
- Fragment;
- Image.

Это помогает быстро проверить, какие данные загрузил Покедекс после правок в админке.

Она показывает:

- текущее состояние;
- текущую миссию;
- активные JSON;
- FPS;
- статус загрузки ресурсов.

В обычном режиме debug-панель скрыта.

Если в `config.json` включён `partyMode: true`, debug-панель скрыта даже при `?debug=1`, чтобы дети случайно не увидели технические данные.

## Архитектура движка

Внутри `script.js` сценарий не зашит. Он только исполняет JSON. Главная точка входа для контента - `content/project.json`: через него приложение находит конфигурацию, миссии, flow, достижения, библиотеки экранов, изображений, аудио, эффектов, текстов и кодов.

Основные части:

- `ResourceManager` загружает и кэширует JSON, изображения, видео и аудио.
- `StateMachine` управляет состояниями: boot, incoming, audio, mission, victory.
- `EventManager` запускает события: звук, медиа, текст, вспышка, переход, вибрация.
- `AudioManager` управляет звуками, категориями громкости и фоновым гулом.
- `AnimationManager` запускает экранные эффекты и конфетти.
- `ProgressStore` сохраняет и восстанавливает прохождение.

## Финальный сертификат

Финальный экран автоматически показывает:

- название команды;
- номер отряда;
- список участников;
- дату прохождения;
- итоговый статус;
- сертификат отряда.

Эти данные берутся из командного прогресса, поэтому сертификат создаётся автоматически для каждой команды.

Новый квест создаётся заменой JSON, картинок и звуков без изменения JavaScript.

## Контентный движок

Движок рассчитан на будущие квесты без переписывания логики. Для новой темы обычно достаточно:

1. Заменить файлы в `images/`.
2. Заменить файлы в `audio/`.
3. Изменить `config.json`.
4. Изменить `missions.json`.
5. При необходимости изменить `flow.json` или порядок сцен через `admin.html`.
6. Проверить `content/project.json`, если вы переименовали основные JSON-файлы.

Все пути к ресурсам должны быть записаны в JSON. В JavaScript не нужно добавлять названия покемонов, тексты, коды, количество миссий или порядок экранов.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите все файлы проекта.
3. Откройте `Settings` -> `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Branch: `main`.
6. Folder: `/root`.
7. Нажмите `Save`.
8. Откройте HTTPS-ссылку GitHub Pages.

## Как опубликовать на Netlify

1. Откройте Netlify.
2. Нажмите `Add new site`.
3. Выберите импорт из Git или ручную загрузку папки проекта.
4. Build command оставьте пустым.
5. Publish directory: корень проекта.
6. Нажмите `Deploy`.

## Как опубликовать на Cloudflare Pages

1. Откройте Cloudflare Dashboard.
2. Перейдите в `Workers & Pages`.
3. Создайте Pages project.
4. Подключите репозиторий или загрузите проект.
5. Framework preset: `None`.
6. Build command оставьте пустым.
7. Output directory: `/`.
8. Нажмите `Deploy`.

## Как установить на телефон

Android Chrome:

1. Откройте HTTPS-ссылку.
2. Нажмите меню браузера.
3. Выберите `Добавить на главный экран` или `Установить приложение`.
4. Запускайте Покедекс с иконки.

iPhone Safari:

1. Откройте HTTPS-ссылку.
2. Нажмите `Поделиться`.
3. Выберите `На экран Домой`.
4. Запускайте Покедекс с иконки.

После первого запуска PWA кэширует основные файлы и продолжает работать без интернета.

## Как сделать резервную копию

Простой способ:

1. Закройте браузер.
2. Скопируйте всю папку проекта.
3. Переименуйте копию, например `Покедекс backup 2026-07-31`.

Если настройки менялись через `admin.html`:

1. Откройте `admin.html`.
2. Нажмите `Экспорт проекта`.
3. Сохраните файл `pokedex-project.json` рядом с резервной копией.

Если нужна резервная копия отдельных файлов:

1. Нажмите `Скачать config.json`.
2. Нажмите `Скачать missions.json`.
3. Сохраните эти два файла рядом с резервной копией.

## Как использовать движок для другого квеста

Логика не зависит от Pokémon. Чтобы сделать другой квест:

1. Замените изображения в `images/`.
2. Замените звуки в `audio/`.
3. Измените тексты в `config.json`.
4. Измените миссии в `missions.json`.
5. При необходимости замените цвета и корпус в `style.css`.

Так можно собрать квест про космическую станцию, пиратов, магическую школу, Minecraft или любую другую тему.
